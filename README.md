# StayHunter — приложение

Мобильный помощник по прибытии: карта, объекты рядом, поиск. Первый шаг —
Стамбул (Султанахмет), данные OpenStreetMap, собранные заранее.

## Что уже есть

- Карта без подписей, светлая и тёмная, компас и «где я»;
- Поиск внизу с кнопкой «Найти» и голосом; разбор фраз по-русски
  («где ближайший банкомат» → банкоматы, «обменять деньги» → обмен);
- Два города: Москва (центр) и Стамбул (Султанахмет) — переключение по нажатию
  на название города;
- Карточка объекта: адрес, часы, сайт или страница OSM, пеший маршрут линией
  на нашей карте (Valhalla), расстояние и время;
- Москва: 1119 объектов; Стамбул: 514.

## Сборка

Собирается **не на сервере владельца**, а в GitHub Actions при каждом push
в `main`. Готовый файл лежит по постоянной ссылке:

**https://github.com/NFlameInvasion/stayhunter-app/releases/download/latest/stayhunter.apk**

Подпись — постоянным ключом из секретов, поэтому новые сборки ставятся поверх
прежних без удаления.

## Устройство

```
lib/
  data/      объекты: модель и загрузка
  geo/       расстояния и минуты пешком
  ui/        экран, категории, карточка
assets/      данные города (pois.json)
tools/       правки Android-каркаса в CI (разрешения, подпись)
```

Серверная часть (C#, PostGIS, поиск, чат) живёт отдельно в
`NFlameInvasion/StayHunter`. Клиент общается с ней по HTTP; сейчас данные
города лежат внутри приложения, чтобы карта работала без сервера.
