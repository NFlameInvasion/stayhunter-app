# Иконка приложения

Иконка нарисована владельцем (бирюзовый силуэт путешественника с чемоданом в рамке)
и переведена в вектор обводкой по его же файлу — форма не перерисовывалась.

Что где:

| Файл | Куда попадает |
|---|---|
| `icon.svg` | исходник 512, любой из PNG снимается из него |
| `icon-maskable.svg` | PWA-иконка в безопасной зоне (если понадобится веб-манифест) |
| `ic_launcher-48/72/96/144/192.png` | `mipmap-mdpi…xxxhdpi/ic_launcher.png`, Android 7 и ниже |
| `ic_launcher_foreground.png` | `drawable-nodpi`, передний слой адаптивной иконки (432 px, прозрачный фон) |

`tools/patch_android.py` кладёт всё это в каркас, который `flutter create` делает
заново на каждой сборке, поэтому файлы живут в репозитории, а не в `android/`.

Фон адаптивной иконки — чёрный (`@color/ic_launcher_background` в `values/colors.xml`),
передний слой уменьшен до 66 % плитки, чтобы рамка не обрезалась круглой маской лончера.

Толщина рамки в исходнике — 1,2 % ширины; на 48 px это полпикселя, поэтому в векторе
она утолщена до 2,1 % (вариант «mid», выбран владельцем).
